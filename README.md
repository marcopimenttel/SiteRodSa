# Site Campanha — Rodrigo Sá 11111

Site institucional de campanha para Deputado Estadual (PP-AM).

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Configuração

Copie `.env.example` para `.env` e preencha:

- `VITE_WHATSAPP_NUMBER` — ativa os CTAs de WhatsApp
- `VITE_CONTACT_EMAIL` — destino do formulário de voluntários
- URLs de X, TikTok e Flickr quando disponíveis

## Fotos

As imagens usadas estão em `public/images/`, geradas a partir de `E:\Sistemas\FotosRodSa\EDITADAS`.
